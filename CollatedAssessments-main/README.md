# CollatedAssessments
This was made by me during my first year with the Usher Institute as an internal tool to extract and view the learning objectives and assessment types of the courses ran by the Usher Institute. 

This software allowed the Usher team to created dashboards viewing these courses to inform them on any under or over focused areas. It would also then go on to help students make informed choices when selecting courses.
Along with the user guide this was made so it could be used in the future by members of the team less savvy in programming.
